# Sophora Guest House website

Build a refined Italian-language, single-page boutique guest-house website at the home address, using only the supplied facts and photography.

## Experience
- Sticky navigation with direct section links and a prominent availability enquiry.
- Full-viewport editorial opening image, concise introduction, image-led rooms, verified trust facts, Alghero, location, gallery, review placeholders, and booking/contact sections.
- WhatsApp is the main direct contact path, including a fixed mobile action.
- Booking.com remains a visually secondary option with a replaceable destination because no property listing URL was supplied.

## Visual direction
- Warm ivory and limestone backgrounds, charcoal type, muted sage and terracotta accents.
- Editorial serif headlines paired with a clean sans-serif interface typeface.
- Asymmetrical photography, minimal framing, restrained motion, and sharp-to-soft modest corners.

## Content safeguards
- Room names, capacities, beds, amenities, review quotes, and unprovided logistics remain clearly labeled placeholders.
- No invented prices, features, timing, awards, or claims.

## Technical details
- Use semantic page sections, native section links, accessible menus and labels, responsive image sizing, reduced-motion support, and structured business metadata.
- Use the supplied images through the project media pipeline.
