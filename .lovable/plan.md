# Fix photograph display and cropping

Preserve the existing Sophora website design while correcting image framing throughout.

## Changes
- Hero: layer the same photograph twice—an understated blurred full-bleed background behind a sharp, fully visible foreground image—so no important room details are cut off.
- Editorial and room photography: remove forced crops, preserve each original 3:2 ratio, and use contained framing with a subtle same-image backdrop only where a fixed visual area is required.
- Destination, gallery, contact, and mobile views: give each image area an appropriate responsive aspect ratio and ensure the complete photograph remains visible without stretching.
- Reduce the hero shading so the photograph remains clear while preserving text contrast.

## Validation
- Check image visibility, distortion, overflow, and composition at desktop landscape, tablet, mobile portrait, and mobile landscape sizes.
- Confirm all original uploaded photographs still load and no site structure, typography, colors, navigation, or content changes.
